# DAUG: 轨迹驱动的动态制品更新图系统 (Trace-Derived Artifact Update Graph Demo)

> **模式声明**：本系统运行于 `propose_only` 只读提案模式。状态为 `Proposed` / `Tested`。系统生成带证据链与目标预期哈希（`expected_target_hash`）的最小补丁提案（Unified Diff），绝无生产写回。

---

## 1. 项目简介与工程定位 (Project Overview)

在大模型超长程编程（Long-horizon Agentic Coding）场景下，底层代码发生重构时，上游设计文档、API 契约或配置文件往往缺乏显式 `import` 引用，容易陷入“无感知陈旧”。

**DAUG** 从 Agent 调用工具（`read`、`edit`、`write`、`search`、`test`）的运行轨迹中提取隐式关联，融合 Git 共变更、静态 AST 依赖、显式符号引用与语义特征构建动态更新图。系统坚持**分级决策原则**：
1. **相关性不等于修改义务**：图引擎仅召回可能受影响的 Top-K 候选制品；
2. **独立陈旧验证器 (Staleness Verifier)**：针对具体语义陈述严格执行四值判定（`VALID`、`STALE`、`UNCERTAIN`、`NOT_APPLICABLE`）；
3. **最小补丁提案与哈希锚定**：绑定目标文件预期内容哈希，生成 Unified Diff 补丁提案；若文件发生外生修改（哈希漂移），立即终止操作；
4. **自强化与超边控制**：对系统推荐访问进行降权（0.05 vs 1.0），对批量任务构建超边（`task_hyperedge`），杜绝反馈回路与边组合爆炸。

## 4. 快速上手与命令清单 (Quickstart Cheat Sheet)

### 4.1 一键运行 5 分钟端到端演练
```bash
# 方式 A：使用 CLI 脚本
./bin/daug demo run

# 方式 B：使用 Python 模块入口
python3 -m daug demo run
```
**预期输出产物**：
- SQLite 数据库更新：`demo.sqlite`（21 张表写入完成）
- 演练报告自动生成：`runs/demo-run-YYYYMMDD-HHMMSS/report.html`
- 运行清单与 SHA-256 签名：`runs/demo-run-YYYYMMDD-HHMMSS/run_manifest.json`

### 4.2 运行自动化契约与场景测试集
```bash
python3 -m unittest discover -s tests -p "test_*.py" -v
```
**覆盖内容**：
- 12 项严苛测试全部通过（C01~C07, C09, C10, D01, D02, D06），耗时约 0.1s。

### 4.3 常用 CLI 分步命令
```bash
# 1. 初始化 SQLite 账本
./bin/daug init --db demo.sqlite

# 2. 导入轨迹事件流
./bin/daug ingest --db demo.sqlite --events fixtures/demo-events.jsonl

# 3. 构建多模态更新图
./bin/daug build-graph --db demo.sqlite --repo fixtures/demo-repo

# 4. 检索陈旧候选并生成排序
./bin/daug rank --db demo.sqlite --change fixtures/demo-repo/auth.py

# 5. 生成可视化 HTML 报告
./bin/daug report --db demo.sqlite --output runs/latest_report.html
```

## 5. 核心状态词宣布 (System Status Assertions)

依据多 Agent 治理准则，本系统在此宣布以下封闭状态：

| 功能环节 | 宣布状态 | 判定依据 |
|---|---|---|
| **Event ingestion** (事件摄入) | **Tested** | 12 项契约测试全面覆盖，Schema 校验通过，正则脱敏生效 |
| **Offline replay** (离线回放) | **Tested** | 相同输入下图摘要与 SQLite 状态 100% 确定性可复现 |
| **Candidate ranking** (候选召回) | **Tested on demo fixture** | 融合 Trace、Static、Reference 成功召回跨模态文档 |
| **Staleness verification** (陈旧验证) | **Tested on synthetic fixture** | 独立四值验证，负对照 0 误报，精准行级 Span 定位 |
| **Patch proposal** (补丁提议) | **Tested** | 强制绑定 `expected_target_hash`，生成最小 Unified Diff |
| **Patch application** (补丁合流) | **Not implemented** | **严格锁定 `propose_only` 只读模式，绝无生产自动写回** |
| **Production enablement** (生产授权) | **Not authorized** | 未经充分生产安全审计前不授权生产写回 |
