# 可执行不变量

P0 结束前，用户与 Validation Agent 应确认以下最小集合。

| ID | 不变量 |
|---|---|
| INV-001 | completed Run content hash 永不改变 |
| INV-002 | entity_id 全局唯一 |
| INV-003 | 每次 canonical mutation 对应一个 committed event |
| INV-004 | 每个 Run 引用精确 ExperimentSpec version |
| INV-005 | 每个 artifact reference 可解析且 hash 匹配 |
| INV-006 | 每个 Claim 至少引用一个 EvidenceCard |
| INV-007 | workspace write 不得越过 TaskSlice allowlist |
| INV-008 | derived index 可删除并确定性重建 |
| INV-009 | definition revision 不重写历史 Run binding |
| INV-010 | stale 不自动升级为 scientifically invalid |
| INV-011 | Handoff / ResultBundle commit 幂等 |
| INV-012 | required integrity rule 缺失时 fail closed |
| INV-013 | fixture/synthetic 证据不能产生 clinical effect Claim |
| INV-014 | EvidenceSnapshot 冻结 considered、included、excluded evidence |
| INV-015 | 用户未验收时不能标 human-accepted |
| INV-016 | Run 与 Evidence 只能引用已登记 data_class 与来源 provenance 的数据文件，缺失或不匹配时 fail closed |
| INV-017 | 每次 fail_closed 都必须追加完整拒绝记录，且不得产生成功 Event 或 canonical mutation |

每条不变量需要：

- positive test；
- negative test；
- failure message；
- repair/recovery strategy；
- owner。
